# 聖經時間軸 Bible Timeline

依時間順序排列舊約與新約的 14 個時代、133 個事件：每個事件有雙語關鍵經文（和合本神版＋KJV）、背景與前因後果、舊約↔新約的預表與應驗、九條神學主題路徑，以及牧者觀點。主軸是大衛・鮑森（David Pawson）《Unlocking the Bible》：每個時代有鮑森導讀，51 個事件以鮑森觀點為首，「鮑森重點」主題線可篩選他強調的立場（以色列的將來、千禧年與再來、正常的基督徒誕生、持守到底、律法與新約）；凱勒、陳恩藩、路易斯、巴刻、柯德納、奈契托為次要觀點。

- `index.html`：App 本體（純前端，無需建置）
- `data/`：時代、主題、牧者名單、事件資料（`events-ot.js`、`events-nt.js`）
- `bible/zh`、`bible/en`：分卷經文 JSON

經文來源：新標點和合本（神版）取自 BibleAquifer（CC0 公有領域）；King James Version（公有領域）。ESV 有版權，僅以外部連結到 esv.org。牧者觀點為轉述摘要，請以原書核對。

GitHub Pages：Settings → Pages → Deploy from branch `main` / root。

## iPhone 使用

用 Safari 打開 GitHub Pages 網址 → 分享 → 「加入主畫面」，就會像 App 一樣全螢幕開啟。讀過的章節會快取，離線也能讀。手機上可左右滑動切換事件或章節，「字級」按鈕調整經文大小。
